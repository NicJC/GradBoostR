# Fast Random Forest Classification (Probabilities)

Internal function returning class probabilities.

## Usage

``` r
rf_predict_fast_class_prob(X, forest_list, n_classes)
```

## Arguments

- X:

  Numeric matrix of features.

- forest_list:

  List of trained trees.

- n_classes:

  Number of classes.

## Value

Numeric matrix of class probabilities.
